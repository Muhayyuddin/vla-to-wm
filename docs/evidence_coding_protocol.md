# Operational rubric for this revision

This document specifies a new selected-example audit. It must not be described as a protocol used during the original divided screening. No independent double coding or agreement statistic was recorded for this audit.

The unit is a claim and its experimental contrast, linked to one source/version and one bibliographic study ID. A study can contribute several contrasts and several limitations. A paper-wide label is inappropriate when experiments answer different questions.

| Field | Rule |
|---|---|
| L1 | Monitoring or correction after an execution error. Extract failure intervention/type, detection quality or delay, recovery success conditional on failure, repeated ineffective actions and intervention burden where available. Aggregate task completion alone is indirect. |
| L2 | Transfer under an explicitly identified shift in conditions. Record what is held out, what was used in adaptation, and the evaluation domain. Separate physical transfer from evaluation inside the learned model. |
| L3 | A defined data burden or data-use question. A pipeline requiring no new task-specific teleoperation can answer that narrow question; it does not by itself estimate hours saved at matched target performance. Separate passive, synthetic and action-grounded populations. |
| L4 | Physical-property/intervention tests connecting prediction to behavior. Video realism or geometry alone is indirect for physical control. |
| L5 | Agreement of the proposed evaluation proxy with the intended reference, including ranking transfer and failure calibration. A direct validation can yield an adverse result. |
| L6 | Constraint violations, uncertainty calibration for the relevant hazard, abstention/fallback behavior, or a clearly stated assurance property. Task value or task completion alone is not such an outcome. |
| Direct | The actual contrast/reference measures the stated, narrowly defined outcome in the declared domain. It may support a package-level conclusion while leaving component attribution unresolved. |
| Indirect | The argument requires transfer from another outcome/domain or an untested attribution. State the missing link. |
| Prospective | The proposed mechanism–outcome link is not tested in the selected cited experiment. Do not count it as an empirical trial. |
| Direction | Favorable, adverse, mixed, inconclusive, or not measured. Preserve adverse tasks and uncertainty; do not convert nonsignificance into equivalence. |
| Baseline | Identify what is held fixed and what changes. Use matched, partially matched, unmatched or no comparator, with a short reason; do not equate a shared benchmark name with a matched experiment. |
| Domain | Physical robot; conventional simulation; learned environment; passive video; or mixed, with the components listed. |
| Attribution | Component ablation, package comparison, observational association, reference validation, or untested hypothesis. This is separate from directness. |

For a future exhaustive heatmap, freeze this protocol, extract every included study, retain page/table locators, and record unavailable information explicitly. Publish both claim-level rows and deduplicated study-level aggregation rules. The present ledger supports only a selected-example illustration. It cannot estimate evidence prevalence among 144 included papers, and empty cells do not demonstrate an absence of evidence.
